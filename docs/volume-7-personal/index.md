# Volumen VII — Personal Knowledge

A diferencia de los demás volúmenes, este **no lo escribe nadie más por
ti** — se alimenta de tu experiencia real. Empieza hoy mismo: la próxima
vez que resuelvas un incidente o cometas un error del que aprendas algo,
documéntalo aquí usando la [plantilla de postmortem](./postmortems/postmortem-template.md).

## Estructura

- **Postmortems** — análisis blameless de incidentes reales que viviste
- 🔜 **Playbooks** — procedimientos paso a paso para situaciones recurrentes
- 🔜 **Lessons Learned** — síntesis cortas de aprendizajes puntuales
- 🔜 **Snippets** — código reutilizable que armas con el tiempo
