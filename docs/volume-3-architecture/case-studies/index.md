# Catálogo de Casos de Estudio

Cada caso sigue la misma estructura: **problema → requerimientos →
arquitectura → diagramas → trade-offs → escalabilidad → costos →
seguridad → disponibilidad**. Requieren haber completado los Niveles 1-3
del **ROADMAP.md** (en la raíz del repositorio) — sin esa base, estos casos se leen
como anécdotas interesantes en vez de lecciones aplicables.

|---|---|---|
| [🎬 Netflix](./netflix.md) | Escalabilidad, resiliencia, chaos engineering | ✅ Disponible |
